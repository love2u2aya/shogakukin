# 奨学金メモ（息子・2027年4月大学進学予定）

> 高校：早稲田大学高等学院 / 進学先：早稲田大学（私立・自宅通学を想定）
> 子ども2人 → 多子世帯（3人以上）の所得制限なし無償化は対象外
> ※家計の具体的な金額はプライバシーのため本ファイルには記載しない

最終更新：2026-06-11

## ⏰ 最優先の締切

| 制度 | 締切 | メモ |
|---|---|---|
| **JASSO 予約採用（大学向け・本命）** | **2026/7/31**（学校指定。**可能な限り 6/30 までに**） | 書類は学院事務所で配布。マイナンバー提出で所得は自動取得 |

- 申込は **必ず高校（早大高等学院）経由**。個人で直接JASSOには出せない。
- 第1回に間に合わなければ **秋（10〜11月頃）の第2回**、それも逃せば入学後の **在学採用（春）**。

## 📌 判定に使う所得（重要）

- 2027年入学の予約採用 → **2025年(令和7年)1〜12月の所得**（令和8年度/2026年度住民税）で判定。
- → **2026年の所得を今から調整しても、この予約採用の判定には反映されない**（2025年分は確定済み）。
- 大学2年目以降は **毎年その時点の最新所得で区分見直し**あり。
- 資産基準：申込時点で本人＋生計維持者の資産合計 **5,000万円未満**（生計維持者2人の場合）。

### 確定申告のどの数字を見るか（自営業の方）
- シミュレーター入力用 → 第一表 **「所得金額等 ⑫合計」**（所得控除を引く“前”）。
- ❌ 差引所得税額・課税される所得金額 は使わない。
- 給付型の公式判定は、これをもとに算出される **住民税の課税標準 → 支給額算定基準額**（マイナンバーで自動取得）。
- 妻（給与のみ）は **源泉徴収票の「支払金額」** を給与収入欄に入れる。

→ 正確な区分は [進学資金シミュレーター](https://shogakukin-simulator.jasso.go.jp/) で確定する。

## 🎯 申し込む奨学金（優先順位）

### 🥇 JASSO 予約採用（大学・本命）
- 給付型（返還不要＋授業料減免）と貸与型（第一種=無利子 / 第二種=有利子）を**同時申込**できる → **両方出す**のが鉄則。
- 私立・自宅通学の目安：給付型満額 約38,300円/月＋減免、第一種 2〜5.4万から選択、第二種 2〜12万。
- 見立て：課税所得が低ければ **給付型の上位区分（満額〜一部）に届く可能性**。要シミュレーター確認。

### 🥈 学院 学内奨学金（高3の今年・給付型）
- **秋季(9月)募集は全学年対象** → 高3も申込可。年30万円前後。返還不要。
- 所得基準（4人家族モデル）：**給与所得なら世帯約500万円以内 / それ以外(自営)の所得なら約130万円**。
- ⚠️ 自営の扱い（給与の線か自営の線か）は **学院事務所に要確認**。
- 申請奨学金は選べない（学校が振り分け）＋募集人数少なく基準内でも不採用あり → JASSOの併願扱い。

### 🥉 大隈記念奨学金（申請不要）
- 年40万円、2・3年生、**成績要件のみ・申請不要**（自動選考）。成績次第で候補に。

### その他
- 都道府県・市区町村奨学金（高校在学中向け、住所地で要確認）。
- 早稲田大学独自の給付奨学金は「自宅外・地方出身」条件が多く、自宅通学だと対象外のことが多い。
