## 📌 判定に使う所得（重要）

- 2027年入学の予約採用 → **2025年(令和7年)1〜12月の所得**（令和8年度/2026年度住民税）で判定。
- → **2026年の所得を今から調整しても、この予約採用の判定には反映されない**（2025年分は確定済み）。
- 大学2年目以降は **毎年その時点の最新所得で区分見直し**あり。
- 資産基準：申込時点で本人＋生計維持者の資産合計 **5,000万円未満**（生計維持者2人の場合）。

### 確定申告のどの数字を見るか（自営業の方）
- シミュレーター入力用 → 第一表 **「所得金額等 ⑫合計」**（所得控除を引く“前”）。
- ❌ 差引所得税額・課税される所得金額 は使わない。
- 給付型の公式判定は、これをもとに算出される **住民税の課税標準 → 支給額算定基準額**（マイナンバーで自動取得）。
- 妻（給与のみ）は **源泉徴収票の「支払金額」** を給与収入欄に入れる。

→ 正確な区分は [進学資金シミュレーター](https://shogakukin-simulator.jasso.go.jp/) で確定する。

## 🎯 申し込む奨学金（優先順位）

### 🥇 JASSO 予約採用（大学・本命）
- 給付型（返還不要＋授業料減免）と貸与型（第一種=無利子 / 第二種=有利子）を**同時申込**できる → **両方出す**のが鉄則。
- 私立・自宅通学の目安：給付型満額 約38,300円/月＋減免、第一種 2〜5.4万から選択、第二種 2〜12万。
- 見立て：課税所得が低ければ **給付型の上位区分（満額〜一部）に届く可能性**。要シミュレーター確認。

### 🥈 学院 学内奨学金（高3の今年・給付型）
- **秋季(9月)募集は全学年対象** → 高3も申込可。年30万円前後。返還不要。
- 所得基準（4人家族モデル）：**給与所得なら世帯約500万円以内 / それ以外(自営)の所得なら約130万円**。
- ⚠️ 自営の扱い（給与の線か自営の線か）は **学院事務所に要確認**。
- 申請奨学金は選べない（学校が振り分け）＋募集人数少なく基準内でも不採用あり → JASSOの併願扱い。

### 🥉 大隈記念奨学金（申請不要）
- 年40万円、2・3年生、**成績要件のみ・申請不要**（自動選考）。成績次第で候補に。

### 🏫 高校在学中（令和8年度・現高3）の制度

#### ① 就学支援金（新制度）＋授業料軽減助成金 ← 要注意・締切近い
- **所得制限なし**で授業料が軽減される（早大高等学院＝私立高校が対象）。
- ①国の就学支援金（上限457,200円）＋②都の授業料軽減助成金（上限43,800円）
  → **合計最大年501,000円**（在学校の授業料が上限）。
- **✅ ①就学支援金は6/4申請済み**（書類に手書きメモあり）。
- **⚠️ ②授業料軽減助成金（都）は7月申請・6月中に学校経由で手続き開始**が必要。
  - 窓口：東京都私学財団 授業料軽減・給付金担当 TEL **03-5206-7925**（平日9:15〜17:00）
  - ①で授業料が全額助成される場合は②の申請不要（学校が案内してくれる）。

#### ② 奨学給付金（東京都私学財団・所得要件あり）
- 授業料**以外**の教育費（教材費・学用品費等）を給付する制度（返還不要）。
- 申請期間：**7月1日〜7月31日**（授業料軽減助成金と同じサイトから同時申請可）
- 所得要件と給付額（年額・全日制）：
  - 住民税非課税・所得割0円 → **152,000円**
  - 所得割合計10万5,500円未満 → **50,670円**
  - 所得割合計18万2,500円未満 → **38,000円**
  - 18万2,500円以上 → **対象外**
- 判定：父（課税所得ゼロ＝所得割ほぼ0円）＋母（給与）の合計所得割額で判定。**対象になる可能性が高い。**
- 必要書類：住民票（世帯全員）・**課税証明書（父母2名分・必須）**・振込口座書類・生徒証等
- 窓口：東京都私学就学支援金センター 奨学給付金担当 TEL **03-5206-7925**（9:15〜17:00）

#### ③ 端末購入支援金（東京都・PCタブレット向け）
- 学校で使う端末（PC・タブレット）購入時の保護者負担を補助する制度。
- 既に「端末購入サイト」で申請している場合、追加書類が必要なケースあり：
  - 多子世帯補助：家族構成が分かる書類（住民票等）をアップロード → 加藤家は子2人で**対象外**。
  - 給付型奨学金（端末購入補助）：入学先学校からの配布資料で確認。
- 問合せ：TEL 03-6636-5675（平日9:00〜18:00）
- 通知：令和8年7月以降に「負担額通知書」が郵送される。

### 貸与型の選択根拠メモ
- 第一種は無利子・所得連動で収入低い時の返済を軽くするセーフティを優先 → 機関保証必須
